# 高校化学 完全攻略プロジェクト

このリポジトリは **ねぐさん専用の化学カルテ兼ノート** です。
Claude のコンテキストは有限なので、「何を学んだか / どこでつまずいたか」は
すべてここにテキストで残します。次のセッションの Claude はまずここを読みます。

姉妹リポジトリ：**Physics**（物理）／**Geography**（地理）

## ディレクトリ構成

| パス | 中身 |
|---|---|
| `CLAUDE.md` | 次回セッションの Claude への引き継ぎ書（最初に読むファイル） |
| `docs/カリキュラム全体像.md` | 化学基礎＋化学の全単元リストと学習順序・依存関係 |
| `docs/暗記を減らす戦略.md` | **化学の核心。覚える量を原理からの導出に置き換える** |
| `docs/間隔反復システム.md` | 忘却対策の仕組み |
| `docs/解法の型カタログ.md` | 大問の解法パターン集 |
| `docs/つまずきポイント集.md` | ねぐさん個人の誤解・弱点の記録（最重要） |
| `progress/理解度マップ.md` | 単元ごとの習熟度（★0〜5） |
| `progress/復習スケジュール.md` | 間隔反復のキュー |
| `progress/学習ログ.md` | 日付ごとの学習記録 |
| `tests/` | 実施したテストの問題・解答・採点結果 |
| `notes/` | 単元ごとの要点ノート |
| `drills/` | 反復用のミニ問題集（各単元の「代表問題」を置く） |

## 使い方

1. セッション開始時：Claude が `CLAUDE.md` → `progress/` を読む
2. 復習キューの処理 → 学習 or テスト
3. 終了時：`progress/` と `docs/つまずきポイント集.md` を更新してコミット
