# 解法の型カタログ（化学）

## なぜ「型」か

Physics 側で決定的な発見があった。ねぐさんは単振動が「苦手」だったのではなく、
**「解き始める場所」を1本だけ間違えて記憶していた**（x = A sinωt から始めていた）。
入口を直した瞬間、直前に断念した発展問題を完答した。

> **「入口はどこか」を型として明示することが、この人には最も効く。**

型は個別知識より忘れにくく、間隔反復にも載せやすい。
**このカタログも `progress/復習スケジュール.md` の反復対象に入れる。**

書式:
```
## 【型名】
- 使う場面:
- 入口（ここから始める）:
- 手順:
- 落とし穴:
- 代表問題:
```

## 【スケールの向きを確定させる型】★ねぐさん固有・2026-09-04 追加

### なぜこの型が要るか（実測に基づく）

診断#000 で **同じ症状が2回出た**。偶然ではなく構造的な弱点。

| | 出題 | 結果 |
|---|---|---|
| A-3 | イオン化エネルギーが大きいのは右上か左下か | **誤答**（左下と回答。自信を伴う誤り）|
| B-7 | ダニエル電池の負極はどちらか | 正解。ただし本人談
「**金がイオンにならないでしょという感覚がなければ詰むとこだった**」|

### 症状
**語呂・順番は思い出せるのに、「どっち端が大きいのか」で詰まる／逆に取る。**

### 原因
**語呂は「順序」を保存するが「向き」を保存しない。**
「貸そうかな まあ当てにすんな…」は誰が左端かを教えるが、
**左端が何を意味するのか**は教えてくれない。

### 対処 ── 端に、物理的実感を1個だけ打ち込む

| スケール | 打ち込む実感 | 出る向き |
|---|---|---|
| **イオン化傾向** | **金は錆びない** | 右端＝イオンになりにくい |
| **イオン化エネルギー** | 希ガスは電子を離さない | 右上が大 |
| **電気陰性度** | **F が最強** | 右上が大 |
| 原子半径 | 電子殻が増えれば大きくなる | 左下が大 |
| 酸の強さ | 塩酸が最強、フェノールが最弱 | — |
| 融点（結晶）| ダイヤは燃えても融けない | 共有結合の結晶が最高 |

**実感は1個でいい。端が留まれば全体の向きが決まる。**

### 落とし穴
1. **名前に引っぱられる。**「イオン化エネルギー」が大きい＝イオンになり**にくい**（名前と逆）
2. 語呂を思い出せたことで安心して、向きを検算しない
3. **「簡単だ」と感じた問題ほど危険。**A-3 は本人が「簡単すぎ」と言った直後の誤答

### 位置づけ
物理側の【検算の型】（次元・特別な値・きれいな形）の化学版。
ねぐさんが B-7 で**自力でやったこと**を、意識的な手順に格上げしたもの。

### 代表問題
`tests/000_診断テスト.md` A-3 / B-7

## 【mol の型】★すべての化学計算の親

### 使う場面
量の計算が出てくるすべての場面。迷ったらまずこれ。

### 入口
**必ず mol に変換する。** g でも L でも個数でも、まず mol に落とす。

```
   質量 w [g] ──÷M──┐
   体積 V [L]（標準状態）──÷22.4──┤
   個数 N ──÷6.0×10²³──┤──→ 【 mol 】──→ 化学反応式の係数比で相手の mol へ
   濃度 c × 体積 V ──────┘                        └→ 求めたい単位へ戻す
```

### 手順
1. 与えられた量を **全部 mol に直す**
2. **化学反応式を書く**（係数を合わせる）
3. 係数比で、求めたい物質の mol を出す
4. 聞かれている単位（g, L, mol/L）に戻す

### 落とし穴
1. **化学反応式を書かずに比例計算を始める**（最頻の事故）
2. 22.4 L/mol を標準状態以外で使う
3. **過不足（限定反応物）を見落とす** → 両方の mol を係数で割り、小さい方が限定
4. 価数を忘れる（中和・酸化還元では mol だけでは足りない）

## 【中和・酸化還元の「釣り合わせる」型】

### 使う場面
中和滴定、酸化還元滴定。**どちらも構造は同じ。**

### 入口
**「何と何を釣り合わせるのか」を最初に宣言する。**
- 中和 → **H⁺ の mol = OH⁻ の mol**
- 酸化還元 → **相手に渡した e⁻ の mol = 受け取った e⁻ の mol**

### 手順
1. 釣り合わせる対象を宣言（H⁺ か e⁻ か）
2. 各物質について「1分子あたり何個出すか」＝価数 or 授受電子数 を出す
3. **価数 × 濃度 × 体積 = 価数 × 濃度 × 体積**
4. 酸化還元なら、半反応式を先に作って授受電子数を確定させる

### 落とし穴
1. **H₂SO₄ の2価、Ca(OH)₂ の2価を忘れる**
2. 酸化還元で「MnO₄⁻ は5個」「Cr₂O₇²⁻ は6個」を半反応式なしで思い出そうとする
   → **半反応式は4手順で必ず作れる**（O は H₂O、H は H⁺、電荷は e⁻）
3. 弱酸でも**中和に必要な量は電離度に関係ない**（滴定の終点は変わる、pH は変わる）

## 【平衡の型】

### 使う場面
化学平衡、電離平衡、緩衝液、溶解度積。

### 入口
**表を書く。「最初 / 変化 / 平衡時」の3行の表。**
いきなり平衡定数の式に代入しようとしない。

### 手順
1. 反応式を書く
2. 3行の表を作る（最初・変化 −x や +2x・平衡時）
3. 平衡時の**濃度**（mol ではなく濃度）を K の式に代入
4. **弱酸・弱塩基なら近似する**：x が小さいので (c − x) ≒ c
5. 出た x で、聞かれているもの（pH など）に変換

### 落とし穴
1. **mol のまま K に代入する**（K は濃度で定義されている）
2. 近似を使わずに二次方程式を解いて時間を溶かす／近似すべきでない場面で近似する
3. 緩衝液で「ヘンダーソン式を暗記して当てはめる」
   → 入口は同じ3行の表。**弱酸とその塩が両方あるだけ**
4. 固体・純溶媒は K に入れない（溶解度積・不均一平衡）

## 【無機：気体の製法の型】★暗記30個を4個に畳む

### 使う場面
「この気体を発生させるには何と何を反応させるか」

### 入口
**「なぜその組み合わせなのか」を4パターンのどれかに分類する。**

| パターン | 原理 | 例 |
|---|---|---|
| 1. **弱酸（弱塩基）の遊離** | 強酸が弱酸を追い出す | CaCO₃ + HCl → CO₂ |
| 2. **揮発性酸の遊離** | 不揮発性の濃硫酸が揮発性の酸を追い出す | NaCl + 濃H₂SO₄ → HCl |
| 3. **酸化還元** | 酸化剤 or 還元剤を使う | Cu + 熱濃H₂SO₄ → SO₂ |
| 4. **熱分解** | 加熱で壊す | NH₄Cl + Ca(OH)₂ → NH₃ |

### 手順
1. 発生させたい気体が、酸性か塩基性か中性かを判定
2. 上の4パターンのどれかに当てる
3. **捕集法は「水に溶けるか」「空気より重いか」だけで決まる**
   - 水に溶けない → 水上置換（最優先。純度が高い）
   - 溶けて重い → 下方置換／溶けて軽い → 上方置換
4. **乾燥剤は「気体と反応しないもの」を選ぶ**
   - 塩基性気体(NH₃)に酸性乾燥剤(濃H₂SO₄)は不可 → ソーダ石灰
   - 酸性気体に塩基性乾燥剤は不可

### 落とし穴
- 個別に丸暗記する（→ 消える）
- 乾燥剤を「相性表」として覚える（→ 酸・塩基の判定で毎回作れる）

## 【有機：構造決定の型】★二次で必出

### 使う場面
「分子式 C_xH_yO_z の化合物Aがある。以下の実験結果から構造を決定せよ」

### 入口
**分子式から不飽和度を計算する。ここが必ず最初。**

**不飽和度 = (2C + 2 + N − H − X) / 2**
- 0 → 鎖状飽和
- 1 → 二重結合1つ or 環1つ
- **4以上 → ベンゼン環を疑う**（環1＋二重結合3 = 4）

### 手順
1. **不飽和度を出す**（構造の大枠が一発で決まる）
2. 検出反応から官能基を確定する（下表）
3. 炭素骨格を分岐込みで数え上げる
4. **最後に必ず分子式に組み直して照合する**

| 実験結果 | 分かること |
|---|---|
| 銀鏡反応 / フェーリング還元 | **アルデヒド**（またはギ酸・還元糖） |
| ヨードホルム反応（黄色沈殿） | **CH₃CO−** または **CH₃CH(OH)−** の構造 |
| FeCl₃ で呈色 | **フェノール性 OH** |
| Na と反応して H₂ | −OH（アルコールまたはフェノール） |
| NaHCO₃ で CO₂ 発生 | **カルボン酸**（炭酸より強い酸） |
| 加水分解して酸とアルコール | **エステル** |
| 臭素水を脱色 | C=C 二重結合 |
| 不斉炭素あり（旋光性）| その炭素に4つ違う基 |

### 落とし穴
1. 不飽和度を出さずに、いきなり構造を書き始める
2. **ヨードホルム反応を「アセトンだけ」と覚えている**（CH₃CH(OH)− も陽性）
3. 異性体の数え上げで漏らす → **主鎖を長い方から順に減らす**手順を固定する
4. 最後の分子式照合を省く

## 【芳香族の分離の型】

### 入口
**酸の強さの順を1本だけ覚える。**

**塩酸 HCl > スルホン酸・カルボン酸 > 炭酸 H₂CO₃ > フェノール**

### 手順
1. **NaHCO₃（炭酸水素ナトリウム）水溶液**を加える
   → 炭酸より強い酸だけが塩になって水層へ ＝ **カルボン酸が分離できる**
2. **NaOH 水溶液**を加える → フェノールも塩になって水層へ
3. **HCl 水溶液**を加える → 塩基（アニリン）が塩になって水層へ
4. 何とも反応しない中性物質（ニトロベンゼン等）はエーテル層に残る

**覚えるのは「強さの順」1本だけ。分離操作は毎回そこから作る。**
