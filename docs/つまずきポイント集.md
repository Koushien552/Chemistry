間違えた問題は必ずここに **「何を誤解していたか」** の形で記録する。
単に「計算ミス」で終わらせず、思考のどこが分岐したかを書く。

書式:
```

- 出題: どんな問題だったか
- 誤答: 何と答えたか
- 誤解の正体: なぜそう考えたか（ここが本体）
- 正しい考え方:
- 再発防止の合言葉:
- 再テスト: 未 / 済(日付・正誤)
```

### [基2] イオン化エネルギーの向きを逆に記憶していた ★第1号・最重要
- 出題: 診断#000 A-3「イオン化エネルギーが最も大きいのは右上か左下か」
- 誤答: **「左下の Fr」**（正解は右上）。自信を伴う誤り
- 誤答時の説明: 「e⁻ を1個手放したい子に e⁻ をプレゼントするのはきついよね」
- 誤解の正体: **「イオン化エネルギー」という名前に引っぱられ、
  「エネルギーの大きさ」ではなく「イオンになりやすさ」を答えていた。**
  イオン化エネルギーが大きい＝イオンになり**にくい**。名前と結論が逆になる語。
  さらに説明が「電子をあげる側のコスト」になっており、定義（＝奪うコスト）とずれていた
- 正しい考え方:
  - **イオン化エネルギー＝電子を1個「引き剥がす」のに必要なエネルギー**
  - Fr は手放したがっている → 安く奪える → **小**
  - F・He は握りしめている → 奪うのが大変 → **大**
  - **本人が得意な電気陰性度と同じ向き。逆なのは原子半径だけ**

  | 量 | 大きいのは |
  |---|---|
  | イオン化エネルギー | 右上 ↗ |
  | 電子親和力 | 右上 ↗ |
  | 電気陰性度 | 右上 ↗（本人はこれを正しく使えている）|
  | 原子半径 | 左下 ↙ ← これだけ逆 |

- 再発防止の合言葉: **「イオン化エネルギーが大きい＝イオンになりにくい。名前と逆」**
- 構造的な意義: **物理の [D4] 並列/直列と完全に同型。**「知識の欠落」ではなく
  「ラベルと中身の誤配線」。しかも本人が「これは簡単すぎだね」と言った直後の誤答。
  → **自己申告が「簡単」の問題こそ危険。**他分野にも同型の誤配線があると考えるべき
- 再テスト: **済(2026-09-04・正)** 確認1〜3を全問正解。下記参照

### [横断] 周期表の議論は「横」と「縦」で支配要因が違う（成功事例）
- 出題: 確認2「F と Cl でイオン化エネルギーが大きいのはどちらか。なぜか」
- 回答: **F。正解。**理由を自力で「クーロン力。近いから強そう」と説明
- 意義: **物理のクーロンの法則をそのまま化学に持ち込んだ。**
  `docs/暗記を減らす戦略.md` の第1層（原理から導く）が実際に機能した例。
  本人は「原子と電子の配置を書かないと説明できない」と、
  **説明に何が必要かを自力で特定してから**答えている
- 整理しておくべきこと:
  - **横（同周期）**：殻は同じ → 陽子が増える → 引力強 → **右ほど大**
  - **縦（同族）**：陽子も増えるが**殻が1つ増える効果が勝つ** → **下ほど小**
  - **「縦は距離が勝つ」**。これで原子半径・イオン化エネルギー・電気陰性度が同時に出る
- 特記: 自信なさげ（「うーん…？」「だっけな」）だが**答えは全問正解**。
  **物理と同じく自己申告が下振れする。**根拠付きで「合っている」と伝えること
- 再テスト: 不要（習慣として継続使用する）

### [基3] 結晶の融点で共有結合の結晶がイオン結晶に勝つことを知らなかった
- 出題: 診断#000 A-4「NaCl・H₂O・ダイヤ・銅で融点が最も高いのは」
- 誤答: 「イオンが強そう」（正解はダイヤモンド）。**迷った上で誤った方を選んでいる**
- 誤解の正体: 知識の穴。**4種類の分類自体は全問正解**しているので、
  分類ができていないのではなく「順位」を持っていないだけ
- 正しい考え方:
  ```
  共有結合の結晶 ≫ イオン結晶 > 金属結晶(幅広い) > 分子結晶
     ダイヤ3550     NaCl 801    Fe1538/Hg−39     氷 0
  ```
  理由：**共有結合の結晶は結晶全体が1個の巨大分子。**融かす＝共有結合を全部切る。
  **金属だけ幅が異常に広い**（水銀は室温で液体、タングステンは3400℃）。
  金属は「順位」ではなく「幅がある」と覚える
- 再発防止の合言葉: **「融点の王者は共有結合の結晶。金属は幅で覚える」**
- 対処: `docs/暗記を減らす戦略.md` 第2層の
  **「4種類の結晶の比較表」に融点の行を足す**（表に畳む）
- 再テスト: **済(2026-09-04・正)** 確認3「SiO₂ と NaCl」で SiO₂ を正答

### [基5] 中和点の液性は答えられるが、理由（塩の加水分解）が出なかった ★重要
- 出題: 診断#000 B-4「酢酸を NaOH で滴定するとき中和点の液性は」
- 回答: **「塩基っぽそう」＝正解。ただし「でも理由は説明できないな」と自己申告**
- 誤った理由づけ: 「酸性はない、**滴定が明らかに終わってない**」
- 誤解の正体: **中和点＝反応が途中、というイメージを持っていた。**
  実際は中和は完了している。酸も塩基も余っていない。
  塩基性になる犯人は**残った塩そのもの**（＝塩の加水分解）で、
  この概念が未整備だった
- 正しい考え方:
  - 中和点の溶液にあるのは **CH₃COONa だけ**
  - `CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻`（加水分解）
  - なぜ右に行くか：**酢酸が弱酸＝ CH₃COO⁻ は H⁺ を欲しがる。**
    だから水から H⁺ を奪い、OH⁻ が残る
  - 一般則は1本：**「強い方が勝つ」**

  | 塩 | 由来 | 液性 |
  |---|---|---|
  | NaCl | 強酸＋強塩基 | 中性 |
  | CH₃COONa | **弱**酸＋強塩基 | **塩基性** |
  | NH₄Cl | 強酸＋**弱**塩基 | **酸性** |

- 再発防止の合言葉: **「弱酸の陰イオンは、塩基として働く」／「強い方が勝つ」**
- 実務的な帰結: **指示薬の選択がここで決まる。**中和点が塩基性側 →
  フェノールフタレイン（8.0〜9.8）。メチルオレンジ（3.1〜4.4）では早く変色して誤る。
  **滴定曲線の問題はほぼこの一点を聞いている**
- 波及: 化4 の**電離平衡・緩衝液・塩の加水分解**に直結。
  超難関二次が目標なので**主戦場**。ここは厚くやる
- 再テスト: **済(2026-09-04・正)** 確認4（NH₄Cl→酸性）・確認5（フェノールフタレイン）を正解。
  さらに**本人が自分の言葉で再構成できた**（「中和完了時にも CH₃COONa が OH⁻ を出す。加水分解」）

### [基6] 金属＋金属イオンの反応を「色」から逆算していた
- 出題: 確認6「AgNO₃ 水溶液に銅線を入れると何が起こるか」
- 回答: 「**Cu²⁺ 発生（きれいな青色と聞いて。）**」→ 部分正解
- 抜けていたもの: **銀が析出すること**（銀樹）。`Cu + 2Ag⁺ → Cu²⁺ + 2Ag↓`
- 誤解の正体: 誤解というより**入口の選び方**。
  結果の色という記憶から逆算しており、**イオン化傾向という導出路を使っていない**。
  B-8（鉄くぎ）では「使いまわし！」と正しく使えていたので、
  **同じ構造の問題だと気づけなかった**のが本体
- 正しい考え方: **金属＋金属イオンを見たら、まずイオン化傾向。**
  Cu > Ag なので Cu が電子を渡して溶け、Ag が析出する。**色は検算に使う**
- 再発防止の合言葉: **「金属＋金属イオンはイオン化傾向。色は答え合わせ」**
- 再テスト: 未

## 参考：Physics 側で見つかっている「誤りの型」

化学でも同じ形が出る可能性が高いので、警戒対象として転記しておく。

### 型1：**自信を伴う誤り**（最も危険）
物理での実例：「並列」と書いてあるのに頭の中で直列の回路図を描いていた。
自信度「簡単！」のまま誤答。**知識の欠落ではなく、ラベルと中身の誤配線。**

> 化学で同じことが起きそうな場所：
> - **酸化と還元の取り違え**（電子を「失う」が酸化。逆に覚えていると全問落ちる）
> - **陽極と陰極**（陽極＝酸化、陰極＝還元。電池の正負極とは別概念）
> - **濃度と物質量**の混同
> - **蒸発と沸騰**、**溶解度**の定義（水100gあたりか、溶液100gあたりか）
>
> → **これらは診断で必ず確認すること。** 自信度も一緒に聞くこと。

### 型2：**入口の誤配線**
物理での実例：単振動を x = A sinωt（＝答え）から解こうとしていた。
正しい入口は運動方程式 ma = −Kx。**入口を直しただけで発展問題を完答した。**

> 化学で同じことが起きそうな場所：
> - 平衡で、3行の表を作らずにいきなり K の式に代入する
> - 構造決定で、不飽和度を出さずに構造を書き始める
> - mol 計算で、化学反応式を書かずに比例計算を始める
>
> → `docs/解法の型カタログ.md` で各単元の「入口」を明示してある。

### 型3：**単位・次元の軽視**
物理での実例：文字式で約分を忘れたが、**単位を組み立てて自力で発見できた**（成功事例）。

> 化学版：**mol 計算で単位を約分して確認する習慣**。
> 「g ÷ g/mol = mol」を毎回声に出させる。
> pH なら「酸なのに pH>7 になっていないか」を必ず確認。
