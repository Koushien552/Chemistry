| | 共通テスト止まりなら | **超難関二次を狙うなら（＝今回）** |
|---|---|---|
| 無機のマイナー知識 | 捨ててよい | **捨てられない**（融合問題で問われる）|
| 平衡の計算 | 基本形まで | **緩衝液・溶解度積・圧平衡定数まで必須** |

> つまり化学は **量を削れない。だから「削る」ではなく「畳む」で勝負する。**
> `docs/暗記を減らす戦略.md` の第1層（原理から導く）と
> 第2層（表に畳む）の比重を上げ、第3層（捨てる）はほぼ使わない。

**朗報もある。** 超難関二次の化学は、暗記量よりも
**「初見の誘導に乗る力」「重い計算を通し切る力」** で差がつく。
ねぐさんは物理の発展診断 #002 で、誘導つきの初見問題を完答している。

## フェーズ2：理論化学を得点源に固定する（9月中旬〜10月）

物理の強みが直結する領域。**ここを先に固めて精神的な支柱にする。**

基5 酸塩基 → 基6 酸化還元 → 化3 熱化学 → 化1 気体 → 化2 溶液 → 化4 平衡

重点:
- **酸化と還元の向き**を絶対に取り違えない型（自信を伴う誤りの警戒対象）
- **半反応式は覚えず4手順で作る**
- 平衡は「3行の表」を入口として固定する
- 弱酸の pH で**近似（c−x ≒ c）**を使えるようにする
- 緩衝液・溶解度積まで到達する（難関大の頻出）

## フェーズ3：無機化学を「導出」に組み替える（10月〜11月）

**最大の地雷。だが正しく組み替えれば暗記量は数分の一になる。**

化5 非金属 → 化6 典型金属 → 化7 遷移元素・錯イオン・系統分離

重点:
- **気体の製法を4パターンに畳む**（弱酸遊離／揮発性酸遊離／酸化還元／熱分解）
- **金属イオンの系統分離フローチャートを白紙再現できるようにする**（無機の半分）
- 色だけは潔く暗記し、**間隔反復に最優先で載せる**（導出不可能な唯一の領域）
- フェーズ2の酸塩基・酸化還元を道具として使い倒す

## フェーズ4：有機化学（11月〜12月）

化8 基礎・元素分析 → 化9 脂肪族 → 化10 芳香族 → 化11 高分子

重点:
- **構造決定の型**（不飽和度 → 検出反応 → 骨格 → 分子式照合）を最初に入れる
- 検出反応の表を白紙再現できるようにする
- **芳香族の分離は「酸の強さの順」1本から毎回作る**
- 高分子は範囲が狭く得点効率が高い。捨てない

## 設計思想

1. **忘れない仕組みが先、新単元は後。** 穴の空いたバケツに水を注がない
2. **暗記量そのものを削る。** 覚える量＝リスク量である
3. **理論を先に固める。** 物理の強みが直結し、無機の道具にもなる
4. **無機の「色」だけは暗記を認める。** 導出できないものを導出させようとしない
5. **超難関二次が目標なので「捨てる」は使わない。** 削るのではなく畳む
6. **自信を伴う誤答を最優先で潰す。** 診断では必ず自信度も申告させる
7. **偏差を縮める。** 理論だけ満点より、3分野で均等に取る方が総合点は高い
