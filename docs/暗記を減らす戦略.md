# 暗記を減らす戦略 — 化学を「覚える教科」から降ろす

## なぜこのドキュメントが化学の心臓部なのか

ねぐさんの確定した課題は **保持（リテンション）** である。
> 「きっと時間が経てばコンデンサーも0点になります」

この特性の人にとって、**暗記量がそのままリスク量**になる。
化学は物理より暗記量が多い。だから素直にやると化学は最悪の教科になる。

**対策は「頑張って覚える」ではない。覚える総量そのものを削ることである。**

やり方は3つ：
1. **原理から導けるものは覚えない**（周期表・電子配置・電気陰性度から大半が出る）
2. **覚えるものは「核」だけに絞り、間隔反復に載せる**（それ以外は捨てる）
3. **バラバラの事実を「表」と「順序」に畳む**（1個ずつ覚えると n 個、表なら1個）

## 第0層：これだけは覚える核（導出不可能）

ここは覚えるしかない。**しかし全部で下記のリストがすべて。** これ以上は増やさない。

### 核A：周期表の最初の20元素＋主要遷移金属
H He Li Be B C N O F Ne Na Mg Al Si P S Cl Ar K Ca ＋ Fe Cu Zn Ag Pb
→ **これがあれば電子配置・イオンの価数・酸化数の大半が自動で出る。**

### 核B：強酸・強塩基のリスト（これ以外は全部弱い）
- 強酸：**HCl, HNO₃, H₂SO₄**（＋HBr, HI）
- 強塩基：**NaOH, KOH, Ca(OH)₂, Ba(OH)₂**（1族と2族の一部）
→ 「弱酸を全部覚える」のではなく「強いのは6個だけ、残りは全部弱い」と覚える

### 核C：イオン化傾向
**K Ca Na Mg Al Zn Fe Ni Sn Pb (H) Cu Hg Ag Pt Au**
「貸そうかな まああてにすな ひどすぎる借金」
→ 電池の正負極・金属と酸の反応・溶液中の析出、全部これ1本で決まる

### 核D：色（これは本当に導出できない。潔く覚える）
| 対象 | 色 |
|---|---|
| Cu²⁺ 水溶液 | 青 |
| Fe²⁺ / Fe³⁺ | 淡緑 / 黄褐 |
| MnO₄⁻ | 赤紫（還元されると無色 Mn²⁺）|
| CrO₄²⁻ / Cr₂O₇²⁻ | 黄 / 赤橙 |

### 核E：定数と定義式
| 式 | 正体 |
|---|---|
| n = w/M = V/22.4 = N/6.0×10²³ | **mol の定義。化学計算の全ての入口** |
| c = n/V（モル濃度） | 定義 |
| pV = nRT | 気体の状態方程式 |
| pH = −log[H⁺]、[H⁺][OH⁻] = 1.0×10⁻¹⁴ | 定義と水のイオン積 |

## 第1層：原理から導く（覚えなくていい）

覚えるのをやめて、**導く手順ごと**覚える。

| 覚えようとしがちなもの | 実際の導き方 |
|---|---|
| 各元素のイオンの価数 | **族番号から。** 1族→+1、2族→+2、16族→−2、17族→−1 |
| イオン結合か共有結合か | **金属＋非金属＝イオン結合、非金属同士＝共有結合** |
| 分子の形と極性 | **電子対の反発（VSEPR）→ 形 → 対称なら無極性** |
| 沸点の高低 | **分子間力の強さ。水素結合(N,O,F) > 極性 > 分子量** |
| 酸化数 | **ルール4つだけ**（単体0／化合物中Hは+1・Oは−2／イオンは電荷／総和＝全体の電荷）|
| 半反応式 | **①主役を書く ②Oは H₂O で合わせる ③Hは H⁺ で合わせる ④電荷は e⁻ で合わせる** |
| 電池の正負極 | **イオン化傾向。イオンになりたい方＝負極（酸化される）** |
| 電気分解で何が析出するか | **陽極＝酸化、陰極＝還元。イオン化傾向で判定** |
| 塩の水溶液の液性 | **「強い方が勝つ」。強酸＋弱塩基の塩→酸性** |
| 平衡がどちらに動くか | **ルシャトリエ。「加えられた変化を和らげる向き」** |
| 有機化合物の反応先 | **官能基が決める。アルコール→酸化→アルデヒド→カルボン酸の一本道** |
| 芳香族の分離 | **酸の強さの順：塩酸 > カルボン酸 > 炭酸 > フェノール** |

> **無機化学が「暗記地獄」になるのは、酸塩基と酸化還元に接続していないから。**
> 気体の製法は「弱酸遊離」「揮発性酸の遊離」「酸化還元」「熱分解」の4パターンしかない。
> 個別に覚えると30個、パターンで覚えると4個。

## 第2層：表に畳む（1個ずつ覚えない）

**バラバラの事実 n 個を、1枚の表として覚える。** 想起も1回で済む。

化学で作るべき表（作ったら `notes/` に置いて反復対象にする）：

1. **4種類の結晶の比較表**（イオン/分子/共有結合/金属：融点・硬さ・電気伝導・例）
2. **気体の製法・捕集・乾燥剤の表**（発生する気体ごと）
3. **金属イオンの系統分離フローチャート**（1枚。これが無機の半分）
4. **定積・定圧… ではなく、各種電池の表**（負極・正極・電解液・全体式）
5. **官能基と検出反応の表**（銀鏡／フェーリング／ヨードホルム／塩化鉄(III)）
6. **糖類・アミノ酸の呈色反応の表**

**表は「見て覚える」のではなく、必ず白紙に再現させる。**（検索練習）

## 化学における「検算の作法」

物理の次元解析に相当するもの。**答えが出たら必ず通す。**

| 場面 | 事前チェック／事後チェック |
|---|---|
| mol 計算 | **単位を約分して mol になるか。**「g ÷ g/mol = mol」を毎回声に出す |
| 濃度 | 薄めたら濃度は必ず下がる。**溶質の mol は変わらない** |
| pH | **酸なら必ず pH<7、塩基なら>7。** 計算結果が逆なら即アウト |
| pH（弱酸） | **強酸の同濃度より必ず pH は大きい**（電離度が小さいから） |
| 中和 | 価数を掛け忘れていないか（H₂SO₄ は2倍） |
| 平衡 | ルシャトリエの向きと、計算で出た向きが一致するか |
| 気体 | 22.4 L/mol を使えるのは **標準状態（0℃, 1013hPa）だけ** |
| 有効数字 | 与えられた数値の桁に揃える |
| 構造決定 | **最後に必ず分子式に組み直して、元の分子式と一致するか確認** |
